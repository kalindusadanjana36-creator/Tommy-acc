TOMMY ACC Gaming Account Store — starter website

HOW TO OPEN
1. Extract tommy_acc_website.zip.
2. Open index.html in Chrome, Edge, or another browser.
3. To publish it publicly, upload the extracted files to a static hosting provider such as GitHub Pages, Netlify, or your existing web host.

CUSTOMIZE BEFORE SHARING
1. Open index.html in a text editor.
2. Find: const WHATSAPP_NUMBER = "947XXXXXXXX";
3. Replace the placeholder with your WhatsApp number including country code, digits only (example format: 94771234567).
4. Edit the demo listings in the `accounts` array to use your real account details and prices.
5. Listings and prices are examples only. This starter does not process payments or verify account ownership.

INCLUDED
- index.html — responsive layout, product search, category filters, WhatsApp links.
- assets/tommy-neon-hero.png — neon gaming artwork.
